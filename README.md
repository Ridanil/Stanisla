# Демо-макет вакансии для Stanisla

Статичный макет страницы вакансии «Специалист по организации склада и рабочих мест» для сервиса ремонта Apple [stanisla.ru](https://stanisla.ru/). Подготовил [@DanilChinin](https://t.me/DanilChinin). Макет закрыт от индексации (`noindex, nofollow`), форма ничего не отправляет.

Файлы: `index.html`, `styles.css`, `script.js`, `assets/`. Без фреймворков и сборщиков. Источники: [VACANCY.md](VACANCY.md) (что сказал владелец в видео) и [STYLE.md](STYLE.md) (разбор стиля сайта).

## Как макет повторяет стиль сайта

Подробности и значения — в [STYLE.md](STYLE.md). Кратко:

- шрифты те же, из Google Fonts: Jura (заголовки), Roboto Mono (текст);
- палитра: акцент `#fc4f00`, красный `#e31e24`, текст `#323130 / #5a5655 / #73706f`, фон `#fcfcfc` с тонкой сеткой «бумаги в клетку»;
- шапка: красно-оранжевая строка с адресами, огромный логотип, меню (добавлен пункт «Вакансии»);
- кнопки «с уголками» и «+», номера секций (01), (02), подвал с градиентным логотипом;
- тон: на «вы», спокойный, предметный.

Картинки (фон первого экрана, фото в «О компании», логотип) скачаны с сайта и сжаты, лежат в `assets/`. Права на материалы принадлежат компании: макет демонстрационный.

## План переноса на Tilda

Сайт собран на Zero Block, поэтому ближе всего повторить его тем же способом. Номера блоков в библиотеке нужно сверить в редакторе (они менялись), ниже — категории.

| Секция макета | Чем собрать на Tilda |
|---|---|
| Шапка с логотипом и меню | Существующий блок шапки сайта: добавить пункт «Вакансии» в меню |
| Первый экран | Zero Block (фон-картинка, заголовок, 3 текста, кнопка-якорь на форму) |
| О компании | Категория «Текст» (TX), блок «Заголовок + текст», либо Zero Block |
| Задачи | «Список» / «Карточки» (категории List и Features), 6 карточек |
| Требования | Категория «Текст» / «Список» (маркированный) |
| Условия | Категория «Список» с двумя колонками (заголовок + описание) |
| Отбор, 4 шага | Категория «Шаги» (Process/Steps), 4 пункта |
| Форма отклика | Категория «Формы» (Form) или Zero Block + Zero Form: поля имя, контакт, ссылка на резюме, комментарий, чекбокс согласия |
| Подвал | Существующий подвал сайта |

Нестандартное в макете: кнопка с уголками (на Tilda — Zero Block с четырьмя линиями и «+»), CSS-маска логотипа с градиентом (на Tilda — готовая PNG/SVG-картинка с градиентом).

**Форма и уведомления:** Tilda → «Настройки сайта» → «Формы» → «Добавить сервис». Для уведомлений на почту указать адрес в получателях формы; для Telegram подключить сервис «Telegram» (бот создаётся в @BotFather, затем `chat_id` вписывается в настройках формы) или передавать заявки через вебхук/Zapier.

## Уточнить у заказчика

- Название должности (в видео не названа; в макете рабочее).
- Оплата, график, тип оформления, испытательный срок.
- Требования к опыту и навыкам (в видео — только «горит этим» и желательно Москва).
- В какой именно точке Москвы работа (на сайте: ул. Казакова, 7) и состав команды.
- Плюсы работы: в макете «свобода предлагать решения», «прямая работа с руководителем», «изучать опыт других производств» (вытекает из слов владельца, но стоит подтвердить).
- Этапы отбора (в видео не описаны; шаги в макете — типовые).
- Канал отклика (в видео: «напишите нам»), адрес почты/Telegram для заявок.
- Расшифровка видео сделана автоматически (Whisper), цитаты в VACANCY.md стоит сверить на слух.
- Ссылка на политику конфиденциальности и пункты подвала (в макете заглушки `#`).
